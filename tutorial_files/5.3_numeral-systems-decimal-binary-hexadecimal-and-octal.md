# Numerical Types:
There are four main types to count number:

1. Decimal
2. Binary
3. Octal
4. Hexadecimal

## Decimal
It is the regular Everyday type of counting. It has base of 10.
ex: 1234 = (1 * 1000) + (2 * 100) + (3 * 10) + (4 * 1)

## Binary
It is the type that computer processes information. It has base of 2.
ex: 101010 = (1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) +
(1 * 2^1) + (0 * 2^0) = 42 

## Octal
It is used for long digits. It has base of 8.

ex: 010 = (1 * 8) + (0 * 1)= 8

## Hexadecimal
It is used to represent very long digits. it has base of 16.

ex: 0xC12 = (12 * 16^2) + (1 * 16^1) + (2 * 1) = 3088

```cpp
#include <iostream>

int main(){
    int test1{16}; //16 in decimal
    int test2{015}; //13 in Octal
    int test3{0xC12}; // 3088 in Hexadecimal
    
    std::cout << test1 << '\n' << test2 << '\n' << test3 << '\n';
    return 0;
}
``` 

Now to output Binary, there are three options:

1. By bitset
2. By print
3. By format

```cpp
#include <iostream>
#include <bitset>
#include <format>
#include <print>

int main(){
    std:bitset<4> test{1010} ; //12 in decimal   
    std::cout << test << '\n';
    std::cout << std::format("{:0b}\n", 0b1010) << '\n';
    std::cout << std::format("{:#0b}\n", 0b1010) << '\n';
    println("{:0b} {:#0b} \n", 0b1010, 0b1010);
    
    return 0;
}

```
