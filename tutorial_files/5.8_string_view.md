# String View

It is a type of reference object which contains a pointer to a string and its size.

It is used when we want to read only the string being initilized. we cannot modify it.

Since it works by pointer and do not copy the original string, it is faster.

it can be used as:

```cpp

#include <string_view>
#include <string>

void testFun(std::string_view in){

  std::string fun{in};
}

using namespace std::string_literals;
int main(){
  
  std::string test1{"Hello"};
  std::string test2{"Hello"s};

  std::string_view out1{"Hello"};
  std::string_view out2{test1};
  std::string_view out3{test2};
  testFun(out1);
  constexpr std::string_view out4{"Hello"};

}
```

string view constexpr will always be compile time replaced.
