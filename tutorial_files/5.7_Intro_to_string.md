# std::string

when we use C-type string literals, it his full of problems, so we use std::string object type strings in c++ to imrpove on it.

use 
```
#include <string>

```
for the lib and initilize the string with 

```
std::string name{value};

```

now if we use it to input the value using cin we will get weird results:

```
std::string name{};
std::string age{};
std::cin >> name;
std::cin >> age;

```

You will notice that in name, if we add name and surname with a whitespace, the name is saved in name but surname separated by space is saved in age, it is due to >> operator, which only gives string before the whitespace, the remaining string is stillin std::cin, thus it is given to age in next line.

It can be fixed with std::getline()

```
std::string name{};
std::string age{};
std::getline(std::cin >> std::ws, name);
std::getline(std::cin >> std::ws, age);

```

you must be noticing that we used std::ws input manipulator for remove any training whitespace and newlines, to fix it from saving newline character in the next input.

## Length of string

To find length of string, we can use the member function of string object, whose syntax is:

```
std::string name{};

int size{static_cast<int>(name.length())};

```

We used casting to convert the output of length to int due to unsigned int warnings, since it returns size_t type.

## Returning and giving std::string to functions:

When we use strings in an function argument, it pass by value, which creates a copy to the function as local variable, which is expensive.

In the same way, when we return a string using function, it first creates a copy of the return string to be passed by value, which is again expensive.
But in modern compilers in c++, there are techniques like RVO(Return Value Optimization) and move sematics.

Do not return string object whenever necessary.

## C-type string literals and std string literals:

Normally, we can initilize the string with c-type string literls, but there are times when std string literals makes things easier.

we can use:

```cpp

using namespace std::string_literals;

std::string name{"Hello"s};

```

the s suffix denotes the string literals.
